# Visual direction

Read this for a vague brief, a new visual world, a landing page, a portfolio, or a result that needs a strong point of view.

Before writing UI, state the direction in one sentence: audience, surface mode, emotional tone, visual character, density, and motion level. Use the product category, audience expertise, brand assets, content volume, platform, and task frequency as evidence. Ask one focused question when the brief does not provide enough direction.

Set the dials deliberately:

- Variation ranges from systematic to asymmetric.
- Density ranges from spacious editorial presentation to compact information work.
- Motion ranges from quiet feedback to deliberate choreography.

Higher settings do not make a result better by themselves. The content and the brand need to support the choice.

Choose a visual world with enough detail to guide type, palette, surfaces, layout, imagery, and a signature detail. A utility product can be precise and calm. An editorial product can use space and contrast. A campaign can use large-scale type and controlled drama. Vary the composition as content changes while keeping orientation clear. The first view of a landing page should explain the product and action before adding visual flourish.

## Optional techniques

- **AIDA** is a copy sequence: attention, interest, desire, then action. It can guide persuasion work and does not fit routine product workflows.
- **Bento** is a modular tile layout. It helps when people compare or scan independent pieces of content.
- **Art-directed presentation** suits expressive marketing and portfolios with strong assets and purposeful motion. It rarely fits a routine utility interface.
- **Timeline-based motion tooling** can coordinate complex scroll and transition work. Use CSS for ordinary feedback and only add specialized motion tooling when the effect requires it.

## Image-first work

Generate visual references when the user requests an image-first concept, a visual board, or close reproduction of a supplied reference. Do not generate images as routine decoration. When the result depends on generated imagery or screenshot fidelity, use the dynamic companion process.
